# Golf Game Master

A simple Python-based golf game where you drag, aim, and shoot the ball to reach the hole in minimum strokes.

## 🚀 How to Run
1. Make sure Python 3 is installed on your system.
2. Install Pygame:
   pip install pygame
3. Clone the repository:
   git clone https://github.com/aaryamahajan919/Golf-game-master.git
4. Open the project folder:
   cd Golf-game-master/Golf-Game-master
5. Run the game:
   python main.py

## 🎮 Gameplay
- Drag with your mouse to aim and set shot power.
- Release to shoot the ball.
- Avoid obstacles and reach the hole with the fewest shots.
